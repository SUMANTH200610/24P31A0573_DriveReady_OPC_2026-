# Day-1: How LLM Works and Your First API Call

## Objective

To understand how Large Language Models work and perform an API call using Python, Groq and LangChain.

## Concepts Covered

- Large Language Models (LLMs)
- API and API keys
- Google Colab
- Environment variables
- LangChain
- ChatGroq
- Prompt and response generation

## Technologies Used

- Python
- Google Colab
- Groq API
- LangChain

## Implementation

1. Install the required Python library.
2. Configure the Groq API key securely.
3. Initialize the LLM using ChatGroq.
4. Send a prompt using the invoke() method.
5. Retrieve and display the AI-generated response.
6. Accept dynamic questions from the user.

## Expected Learning Outcomes

- Understand basic LLM functionality.
- Connect an application to an AI model.
- Perform API calls using Python.
- Handle API credentials securely.

## Security

API keys are stored securely using Google Colab Secrets and are not included in the source code.
